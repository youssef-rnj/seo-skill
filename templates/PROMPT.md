# Prompt for any website

Paste into Claude Code (opened in the website's project folder) after filling the brackets.
With the skill installed, this prompt triggers it; without the skill, it still works on its own.

---

Run a full SEO and AI-search setup for this website, step by step, using the seo-skills method.

- Website: [https://example.com]
- Business: [name, what it does, city/country]
- Clients wanted: [who, where, priority services]
- Languages: [fr / nl / en / ar …]
- Code: [this folder / repo] — stack: [Next.js / Vite+React / WordPress / other]
- Deploy: [e.g. push to main → auto-deploy]
- Official facts (use only these): [legal name, company number, address, phone, email, hours, founding date, team names and titles, official social profiles]

Rules: do not change any visible text without my approval for that change; never invent facts (mark
them TO VERIFY); ask before every deploy, publish or external submission; never type passwords; check
desktop and 375 px; stop after each step and wait for my OK.

Steps: 1 audit with a score /100 (read only) · 2 technical fixes · 3 AI-search readiness · 4 Search
Console, Bing, Google Business Profile · 5 content plan as drafts · 6 visibility kit · 7 report with
before/after score and next 3 actions.
